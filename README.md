## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

日志里经常混进手机号、身份证号这类信息，排查问题时总担心把敏感数据带出去。请从零实现一个数据脱敏库，仓库里目前只有一个空的 Maven 工程（pom.xml 只有 JUnit 5 与 AssertJ）。要求：1) 注解驱动：用 `@Sensitive(strategy=...)` 标注字段，内置手机号、身份证、银行卡、邮箱、姓名、地址六种策略，并允许自定义策略实现；2) 递归处理：对嵌套对象、集合、Map、数组以及带循环引用的对象图都能正确脱敏，且不得因循环引用导致栈溢出；3) 作用范围控制：支持按分组启用（例如日志场景与审计场景采用不同策略），并支持用 `@SensitiveIgnore` 排除字段；4) 输出形式：既能把对象脱敏成副本，也能输出脱敏后的 Map/JSON 结构；前者不得修改原对象，需有测试证明；5) 日志集成：提供一个日志格式化钩子接口，并给出接入常见日志框架的示例（不强制绑定具体实现）；6) 异常处理：字段访问失败或策略抛异常时不得中断整个脱敏流程，需记录并按配置选择保留原值或替换为占位符；7) `mvn -q verify` 跑通，覆盖六种内置策略、递归与循环引用、分组、副本不可变性、异常隔离五类测试；8) README 说明策略清单与扩展方式。
